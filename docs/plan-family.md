# 出遊模式規劃：家人定位、找人、代買／記帳

2026-11-08 與使用者確認：保留找吃找玩，加家人定位；全家都是 iPhone；先規劃不實作。

## 先用現成的（免開發）
- iPhone「尋找」＋家人共享：背景也會更新位置，可對家人的手機「播放聲音」（靜音模式也會響）。看不到樓層。
- 設定：設定 → 自己的名字 → 家人共享 → 位置分享 全開；小孩用家長建立的兒童帳號。

## 網頁做不到的
- 背景定位：App 關掉或鎖螢幕就不更新。
- 遠端讓手機響：只能發推播通知（iOS 16.4+、需加到主畫面並允許通知），靜音模式下只會震動，不能強制大聲響。
- 自動樓層：網頁讀不到氣壓計，GPS 高度室內誤差約 3 層樓。

## 第一階段：家人分頁（Firebase Firestore，匿名登入）
- 家族碼加入（放進設定碼），每人設名字與頭像 emoji
- App 開著時每 30 秒回報位置
- 「我在這」：大按鈕選樓層（B3–10F）＋一句話＋可拍一張周圍照片（找人最有效）
- 家人卡片：距離、方向、樓層、幾分鐘前更新、導航
- 📣 集合：集合地點＋樓層＋時間，發給全家

## 第二階段：找人推播（需 Firebase Cloud Functions，Blaze 方案綁卡，免費額度內 0 元）
- 按「找他」→ 對方收到通知（有提示音）→ 點開自動回報位置，跳出「你在幾樓？」＋拍照
- 對方回報後我方手機提示

## 第三階段：代買清單、臨時記帳
- 代買：共用清單（誰要什麼、誰負責買、已買打勾、金額）
- 記帳：誰付了多少、哪些人分攤，最後自動算「誰該給誰多少」
